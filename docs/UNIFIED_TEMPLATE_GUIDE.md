# 統一学習テンプレート使用ガイド

## 概要

WasabiOS技術解説ドキュメントシステムでは、すべての技術トピックに対して統一された学習体験を提供するテンプレートシステムを採用しています。このガイドでは、新しい技術解説ページを作成する際の手順と、テンプレートの活用方法について説明します。

## 学習フローの設計思想

### 4段階の統一学習体験

1. **🌍 技術全体像** - その技術が属する領域全体の俯瞰
2. **🎯 位置づけと必要性** - システム内での役割と存在理由
3. **⚙️ 実現技術** - 具体的な仕組みと実装
4. **🔗 学習の完結** - 要点整理と次のステップ

この構造により、学習者は「全体感 → 位置づけ → 必要性 → 実装技術」という自然な流れで理解を深めることができます。

## 依頼文生成システムの使用方法

### 1. 基本情報の入力

- **トピック名**: 解説する技術の名前
- **カテゴリ**: グラフィックシステム、メモリ管理、システム基盤、開発ツール
- **難易度**: 初級、中級、上級
- **関連ファイル**: 実装に関連するソースファイル

### 2. 解説内容の記述

具体的に解説したい内容を詳細に記述します。例：

```
- ヒープメモリの管理方法
- アロケーションアルゴリズムの比較
- フラグメンテーションの問題と対策
- 実際のメモリ使用パターンの分析
```

### 3. 特別な要求（オプション）

図示したい内容やアニメーション要素があれば記述します。例：

```
- メモリレイアウトの図示
- アロケーション/デアロケーションのアニメーション
- 異なるアルゴリズムのパフォーマンス比較チャート
```

## 生成される依頼文の構造

### 統一学習体験での解説要求

#### 1. 🌍 技術全体像の解説
- 当該技術が属する技術領域全体の俯瞰図（インタラクティブマップ）
- 関連技術との系統関係（技術系統樹の可視化）
- この技術分野の発展史と現在の位置づけ
- 「あなたはここにいます」的な位置表示

#### 2. 🎯 システム内での位置づけと必要性
- WasabiOS全体アーキテクチャでの当該技術の位置
- 上位技術（何に使われるか）と下位技術（何を使うか）の関係図
- 他の選択肢との詳細比較表と採用理由
- 具体的に解決する問題の詳細説明
- この技術がない場合の困りごとと実際の問題発生シナリオ

#### 3. ⚙️ 実現技術の詳細
- 基本動作原理の段階的図解
- 「なぜそうなるのか」の理由を重視した仕組みの説明
- WasabiOSでの実際の実装コード例
- コードと動作の対応関係の可視化
- 実装時のポイントとトラブルシューティング

#### 4. 🔗 学習の完結と次のステップ
- 学習内容の要点整理
- 関連トピックへの自然な導線
- 推奨学習順序の提案
- 理解度チェックポイント

### 統一視覚化要求

- 技術領域マップ（インタラクティブ、クリック可能）
- システム全体アーキテクチャ図での位置表示
- 動作原理のステップバイステップアニメーション
- 問題→解決の流れを示すフローチャート
- 代替技術との比較表（視覚的）
- コード実行と結果の対応関係図

### 学習体験の設計要求

- 一つのページで完結する学習体験
- スクロールに応じた段階的な理解促進
- 各セクション間の自然で論理的な流れ
- 全体像→位置づけ→必要性→実装の一貫した構造
- 理解の各段階での「なるほど！」体験の創出

## HTMLテンプレートの構造

### セクション構成

新しいテンプレート（`docs/template.html`）は以下の4つのセクションで構成されています：

1. **技術全体像セクション** (`section-overview`)
   - 技術マップ: `{{TECH_MAP}}`
   - 全体図: `{{TECH_OVERVIEW_DIAGRAM}}`

2. **位置づけと必要性セクション** (`section-positioning`)
   - システム図: `{{SYSTEM_ARCHITECTURE_DIAGRAM}}`
   - 比較表: `{{COMPARISON_TABLE}}`
   - 問題説明: `{{PROBLEM_DESCRIPTION}}`

3. **実現技術セクション** (`section-implementation`)
   - 基本原理: `{{BASIC_PRINCIPLE}}`
   - 実装コード: `{{IMPLEMENTATION_CODE}}`
   - 実装ポイント: `{{IMPLEMENTATION_POINTS}}`

4. **学習完結セクション** (`section-conclusion`)
   - 要点整理: `{{SUMMARY_POINTS}}`
   - 次のステップ: `{{NEXT_STEPS}}`

### プレースホルダー一覧

| プレースホルダー | 説明 |
|---|---|
| `{{TITLE}}` | 技術名 |

| `{{SUBTITLE}}` | サブタイトル |
| `{{CATEGORY}}` | カテゴリID |
| `{{CATEGORY_NAME}}` | カテゴリ名 |
| `{{RELATED_FILES}}` | 関連ファイル |
| `{{TECH_MAP}}` | 技術マップHTML |
| `{{TECH_OVERVIEW_DIAGRAM}}` | 技術全体図HTML |
| `{{SYSTEM_ARCHITECTURE_DIAGRAM}}` | システム図HTML |
| `{{COMPARISON_TABLE}}` | 比較表HTML |
| `{{PROBLEM_DESCRIPTION}}` | 問題説明HTML |
| `{{BASIC_PRINCIPLE}}` | 基本原理HTML |
| `{{IMPLEMENTATION_CODE}}` | 実装コードHTML |
| `{{IMPLEMENTATION_POINTS}}` | 実装ポイントHTML |
| `{{SUMMARY_POINTS}}` | 要点整理HTML |
| `{{NEXT_STEPS}}` | 次のステップHTML |
| `{{SECTION_SPECIFIC_JS}}` | セクション固有JavaScript |
| `{{CUSTOM_JS}}` | カスタムJavaScript |

## 学習進捗機能

- スクロール位置に基づく現在セクションの検出
- 右上の進捗インジケーターでの進捗表示
- セクション変更時のイベント発火

```javascript
});
```

## ベストプラクティス

### 1. 段階的理解の促進

- 各セクションで前のセクションの内容を前提とする
- 理解チェックポイントで学習者の理解を確認
- 複雑な概念は身近な比喩で説明

### 2. 視覚的要素の活用

- 図解やアニメーションで抽象的概念を具体化
- インタラクティブ要素で学習者の参加を促進
- 色分けやアイコンで情報を整理

### 3. 実装との対応

- コードと説明を密接に関連付ける
- 実際のWasabiOSでの使用例を示す
- トラブルシューティング情報を含める

## まとめ

この統一学習テンプレートシステムにより、どの技術トピックについても一貫した高品質な学習体験を提供できます。依頼文生成システムを活用して、効率的に技術解説ページを作成し、WasabiOSの学習リソースを充実させていきましょう。
